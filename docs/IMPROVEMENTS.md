# Improvements

Changes that would make CE Decky better and that nothing owes. The product is correct without each of them: what the device does today is stated in `DESIGN.md` and is true, and a row here is a better answer to a case that already has a safe one.

This list is not `FIELD_NOTES.md` **Still worth checking**. That section holds what this project has not confirmed, and `scripts/check_release.py` refuses a stable tag while it holds a row. Nothing here holds a release. A row moves there only when what the product does today in its case turns out to be wrong rather than merely limited, and a row is deleted here in the change that builds it.

Each row names what already exists, so the next person starts from it rather than from the idea, and what has to be true before the improvement reaches a user.

| Improvement | What exists | What it needs before it is offered |
|---|---|---|
| Distinguish an activated script from validated targets and a confirmed gameplay effect, and offer address repair only for a reviewed recipe | The record that a table worked is written from one cheat's acknowledged activation and active readback, and the table this was found on earned it while its two ammo scripts did nothing. A live Lua-timer case stayed active with an invalid player chain; the agent procedure in `TABLE_REPAIR.md`, `target_table_memory.py`, `table_repair.py` and the mutating `target_runtime_control.py` now cover exact identities, bounded observations, script export, structural assertions, awaited command ACKs and separate reviewed copies. A broader device experiment distinguished restored fields and triggered hooks from absent conditional equipment and an incompatible form renderer | Review and implement optional exact-table/build health assertions, separate addressing/write/gameplay evidence, explicit waiting/mismatch/validated states and transient loading/respawn handling. A recipe must prove each dependency independently, retain ambiguity and obtain fresh consent for its new SHA; arbitrary Lua or one readable pointer cannot supply that proof. Every diagnostic and refusal must reach the support bundle within existing budgets, with regressions. No automatic permanent mark may follow from an unavailable player, and every advisory mark stays clearable offline |
| A cheat that cannot be switched off safely is taken out of the prepared copy, rather than reported and left on | The transform is written: the hook belongs to a scan symbol, and dropping that symbol removes it with both existing proofs. Measured at 5 blocks, 90 lines and 2264 bytes on the table this was found in | The cost report counts a record whose address the removal took and a script the removal emptied; a record whose flag no longer has any reader is neither, so such a cheat would go quietly and has to be counted. `prepare_table_copy` carries it as a third transform beside the signature and the unmatched scans, in the same press and the same copy. And a game that dies seconds after CE Decky wrote anything is the only signal for the shapes the reader cannot follow: correlating the game's own exit with the write is what would turn those into something the user is told about rather than left to guess |
| A flag whose hook changes a register only on its on side is proven safe to switch off, rather than left on | The hook reader refuses any register load, push or pop on either side of a flag's test, because it does not know which side runs when the flag is off. On the table the crash came from that refuses three flags whose off side is the original code (14 of 22 safe rather than 17), and 44 of 67 over the 12 tables on the Steam Machine rather than 51 | The side that runs when the flag is off, read from the record's own off key against the test's literal and the branch's condition, for `je`/`jne` and their aliases at least, with every other condition still attributed to both sides. Each test of the flag decided separately, since a hook may test it more than once. A flag with no record, or whose record has no off key, keeps today's answer. The reader's one-direction rule holds throughout: a shape the direction cannot be read for stays refused |
