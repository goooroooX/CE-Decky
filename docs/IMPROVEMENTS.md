# Improvements

Changes that would make CE Decky better and that nothing owes. The product is correct without each of them: what the device does today is stated in `DESIGN.md` and is true, and a row here is a better answer to a case that already has a safe one.

This list is not `FIELD_NOTES.md` **Still worth checking**. That section holds what this project has not confirmed, and `scripts/check_release.py` refuses a stable tag while it holds a row. Nothing here holds a release. A row moves there only when what the product does today in its case turns out to be wrong rather than merely limited, and a row is deleted here in the change that builds it.

Each row names what already exists, so the next person starts from it rather than from the idea, and what has to be true before the improvement reaches a user.
