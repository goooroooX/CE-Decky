# CE Decky 0.9.35

A table that worked on a non-Steam game is now remembered as working for as long as the game's executable stays the same, and FearLess search is ready about an hour after a first install instead of more than five.

## New

- A table that worked on a game with no version number, which is common for non-Steam games, is marked **Worked with this executable** with the solid green ring. It asks for a retest once the game's executable changes.

## Fixes

- FearLess search no longer misses a game whose topic the forum had just moved, and finds a topic titled only in another script for a game that also has an English name.
- A cheat with a fixed list of values offers only that list in **Configure cheats**, with no field to type another, and nothing outside the list is written into the game.
- A value saved outside such a list by an earlier version no longer stops **Apply** and **Load last table & cheats** for the whole table. The cheat's row says so, and choosing a value from the list replaces it.
- A cheat whose only choices are Disabled and Enabled is a plain on/off switch rather than a list.
- In **Advanced…**, **Table sources**, a FearLess refusal is counted once rather than twice, and background reading is no longer counted as a search.

## Changed

- FearLess search stays up to date with far fewer requests to the forum, usually one page a day, so it is refused less often.
- Opening the panel while Cheat Engine is running shows what pinned values hold in the game now, not what they held when the panel was last open.
- **Configure cheats** moves helper scripts that change nothing in the game by themselves behind **Scripts**. The values inside them stay in the list and show their current value without you switching anything on.
- The record of tables that worked is converted once when this version first starts, with every mark kept. An older version cannot read it, so going back to one means every working table asks for a retest.

## Install

Close any running game, then update from the CE Decky panel. If the panel does not offer it, open **Advanced…**, then **Plugin updates**, and press **Check now**. On Decky Loader 3.3.0 that needs 0.9.30 or later installed: an older version cannot reach the network there, so turn on **Developer mode** in Decky and install `CE-Decky-v0.9.35.zip` from the file. Your tables, authorizations and profiles are kept. The previous record of tables that worked is kept beside the new one as `table_compatibility.before-schema-4.json`.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
