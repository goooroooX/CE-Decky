# CE Decky 0.9.33

Updates now show what a new version changes before you install it, and your cheats keep the values you set.

## New

- The update window shows what a new version changes before you press **Update**.

## Fixes

- **Load last table & cheats** no longer writes last session's number back into a cheat you never switched on, such as a level or experience value.
- A value you set for a cheat that is off no longer jumps back to what the game holds; where the two differ, the game's own number is shown beside it as **Current**.
- A script's setting, such as a jump multiplier, takes effect while that script runs; any other cheat's value is applied when you switch that cheat on.
- Emptying a value and pressing **Apply** forgets it, and the row shows what the game holds again.
- CE Decky offers its updates once a day to everyone who opens its panel, not only after a table search.

## Install

Close any running game, then update from the CE Decky panel. If the panel does not offer it, open **Advanced…**, then **Plugin updates**, and press **Check now**. On Decky Loader 3.3.0 that needs 0.9.30 or later installed: an older version cannot reach the network there, so turn on **Developer mode** in Decky and install `CE-Decky-v0.9.33.zip` from the file. Your tables, authorizations and profiles are kept.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
