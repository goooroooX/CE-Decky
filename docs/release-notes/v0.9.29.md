## New

- Review tells you when a table looks for code that is not in your copy of the game, and which pattern it is, so a table that would load and then do nothing is something you find out before you agree to it. It is checked only where CE Decky already knows which program the game runs.
- Review tells you when a table is signed, and that Cheat Engine refuses those here, before you start a game to find out. One press makes a copy without the signature and opens it for review, so you agree to the bytes that actually get loaded; rows carrying a signature are marked, and a copy CE Decky made says which table it came from.
- That same press also takes out the code that needs a pattern your copy of the game does not have, and a table with both problems is fixed in one copy rather than two. The copy's review says what was removed and whether any cheat went with it. If a table you already agreed to turns out not to work, the question about it now offers to try a repaired copy before offering to stop using it, and says so plainly when no repaired copy can be made.

## Changes

- A cheat that is simply on or off is a switch now, with no value to choose and no field to fill: for one real table that is 24 switches in place of 48 controls. Switching one off writes its off value, so the cheat really stops.
- Panel messages start with what was found rather than with what CE Decky was doing, so the reason is the part you can read without opening the row.

## Fixes

- Stopping Cheat Engine leaves the game as it was found. Cheats are switched off first, so a game no longer keeps running with the changes a stopped Cheat Engine made and could no longer undo. If one will not switch off, CE Decky says which and that restarting the game clears it.

- Switching on one cheat no longer brings the rest of the table with it. A table's script can declare most of its own flags as on, so one cheat could quietly mean damage multipliers and movement speed as well; now only what you switch on is switched on, the count on the panel is what is running, and Review says up front how much the table turns on by itself.

- A game whose executable is very large declares its version again, so its tables can reach the green compatibility mark instead of staying on the grey one. A table already proven here keeps its current mark until a cheat from it works once more.

## Install

Turn on **Developer mode** in Decky, install `CE-Decky-v0.9.29.zip` from the file, then open the Quick Access Menu. Your tables, authorizations and profiles are kept.

An installed 0.9.28 or newer can install this from the panel itself.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
