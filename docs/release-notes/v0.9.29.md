## New

- Review tells you when a table looks for code that is not in your copy of the game, and which pattern it is, so a table that would load and then do nothing is something you find out before you agree to it. It is checked only where CE Decky already knows which program the game runs, and a table that looks inside one of the game's other files is checked there too.
- Review also tells you when a pattern matches more than one place in your copy of the game. Cheat Engine picks any one of them, so a cheat built on that pattern can end up changing the wrong code - on a table that otherwise looks perfectly fine.
- Review tells you when a table is signed, and that Cheat Engine refuses those here, before you start a game to find out. One press makes a copy without the signature and opens it for review, so you agree to the bytes that actually get loaded; rows carrying a signature are marked, and a copy CE Decky made says which table it came from.
- That same press also takes out the code that needs a pattern your copy of the game does not have, and a table with both problems is fixed in one copy rather than two. The copy's review says what was removed and whether any cheat went with it. If a table you already agreed to turns out not to work, the question about it now offers to try a repaired copy before offering to stop using it, and says so plainly when no repaired copy can be made.

## Changes

- CE Decky updates itself only while no game is running. It still tells you about an update during a game, but pressing Update then asks you to close the game first. An update that finishes downloading after you started a game waits for it to close before installing.
- A cheat that is simply on or off is a switch now, with no value to choose and no field to fill: for one real table that is 24 switches in place of 48 controls. Switching one off writes its off value, so the cheat really stops. A cheat that does choose between things shows its list alone, with a box for a value the author did not list one press away.
- Panel messages start with what was found rather than with what CE Decky was doing, so the reason is the part you can read without opening the row.

## Fixes

- Stopping Cheat Engine leaves the game as it was found. Cheats are switched off first, so a game no longer keeps running with the changes a stopped Cheat Engine made and could no longer undo. If one will not switch off, CE Decky says which, and Home asks you to restart the game before a table is started in it again, with **Clear** for when you already have.
- Stopping Cheat Engine with Auto-load on no longer starts it straight back. Auto-load stays switched on and waits for the next run of the game; starting a table yourself, or switching Auto-load on again, starts it sooner.
- Switching Auto-load on while the game is running starts the table right away, rather than only after the panel was closed and opened again.
- Switching on one cheat no longer brings the rest of the table with it. A table's script can declare most of its own flags as on, so one cheat could quietly mean damage multipliers and movement speed as well; now those are switched back off, and Review says up front how much the table turns on by itself. A flag whose code could not be proven to survive being switched off is left on rather than risk the game, and the panel names it so you can switch it off yourself.
- A game whose executable is very large declares its version again, so its tables can reach the green compatibility mark instead of staying on the grey one. A table already proven here keeps its current mark until a cheat from it works once more.

## Install

Turn on **Developer mode** in Decky, install `CE-Decky-v0.9.29.zip` from the file, then open the Quick Access Menu. Your tables, authorizations and profiles are kept.

An installed 0.9.28 or newer can install this from the panel itself; close any running game first.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
