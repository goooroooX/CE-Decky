# CE Decky 0.9.34

Your cheats come back on with one press, and a single cheat that fails no longer stops the rest from working.

## New

- With Cheat Engine already running, **Configure cheats** selects the cheats you had on last time, so one **Apply** turns them all back on. Close it without applying to leave everything as it is.

## Fixes

- When one cheat does not work in your version of the game, the other cheats you applied still switch on. A window names the ones that did not and why, they stay off the next time the game starts, and CE Decky no longer offers to stop using a table that otherwise works.
- Moving through the panel with the controller no longer stops on every cheat listed as on. Up to seven are shown, by their short names.
- **Configure cheats** says why some cheats show no **Current** value: the script they need is off.
- In **Advanced…**, **Table sources**, the **?** beside a source lists its recent errors, when they happened and why, so an error count beside **Working** is no longer a mystery.

## Changed

- A fixed copy of a table carries a green **Fixed** label in **Manage** and in search. A table fixed with a coding agent, as the README describes, shows up the same way beside the original, and its review names any cheats the copy no longer has.

## Install

Close any running game, then update from the CE Decky panel. If the panel does not offer it, open **Advanced…**, then **Plugin updates**, and press **Check now**. On Decky Loader 3.3.0 that needs 0.9.30 or later installed: an older version cannot reach the network there, so turn on **Developer mode** in Decky and install `CE-Decky-v0.9.34.zip` from the file. Your tables, authorizations and profiles are kept.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
