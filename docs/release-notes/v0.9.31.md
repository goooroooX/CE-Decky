# CE Decky 0.9.31

Fixes cases, in some tables, where a cheat stayed on or came back after you switched it off, or where **Load last table & cheats** failed; Auto-load also gives a game time to load before it starts.

## Fixes

- In tables that keep a script's own switches outside it, switching that script on no longer leaves them on without saying so, from the panel, in **Configure cheats** or at Auto-load.
- **Disable all** also puts back a cheat that showed off but was still active in the game, and a cheat it switched off no longer comes back at the next Auto-load.
- **Load last table & cheats** no longer fails because of a value set for a cheat that was off, or a setting inside a script that stays off.
- A script cheat with settings, such as jump or health, stays on while you switch other cheats; switching a script off switches off everything under it.
- A cheat inside a script that has not run yet can be switched on, in **Configure cheats** and from a pinned cheat.
- A table is no longer said to be written for a different build of the game when the game closed or every pattern it looks for is there, and a working table gets its green check.
- No more "Cheat Engine could not be launched" after a game exits or crashes with Cheat Engine attached.

## Changed

- **Load last table & cheats** waits until the game has been running for 10 seconds, and counts the wait down, so a table is not marked as not working because the game was still loading.
- **Configure cheats** opens with every cheat collapsed, and lists under **Scripts** only the scripts that hold other scripts.

## Install

Close any running game, then update from the CE Decky panel. On Decky Loader 3.3.0 that needs 0.9.30 installed: an older version cannot reach the network there, so turn on **Developer mode** in Decky and install `CE-Decky-v0.9.31.zip` from the file. Your tables, authorizations and profiles are kept.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
