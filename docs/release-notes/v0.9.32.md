# CE Decky 0.9.32

Lets more non-Steam games, and games on a Proton your Linux distribution installed, start Cheat Engine.

## Fixes

- Some non-Steam games running under Proton could not start Cheat Engine: **Advanced** said "Proton not observed" and **Load table & start CE** said the game was not running.
- A game running under a Proton your Linux distribution installed, such as `proton-cachyos` on CachyOS, can start Cheat Engine instead of failing with "no installed Proton tool matches".
- Cheat Engine stops by itself shortly after the game closes. It could stay attached, with the game still shown as running and **Change** unavailable, until you pressed **Stop CE**.

## Install

Close any running game, then update from the CE Decky panel. On Decky Loader 3.3.0 that needs 0.9.30 or later installed: an older version cannot reach the network there, so turn on **Developer mode** in Decky and install `CE-Decky-v0.9.32.zip` from the file. Your tables, authorizations and profiles are kept.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
