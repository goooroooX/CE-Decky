# CE Decky 0.9.30

Decky Loader 3.3.0 broke CE Decky's network access. It moved Decky's built-in Python from 3.11 to 3.14 and left out a standard module, `pathlib.types`, that CE Decky's networking library needs. On Decky Loader 3.3.0 Search finds 0 tables in every source, no table can be downloaded, and CE Decky cannot check for or install updates. This release supplies that module. If you are on Decky Loader 3.2.8, you were not affected.

## Fixes

- Search, downloads and CE Decky's own updates work again on Decky Loader 3.3.0.
- On Decky Loader 3.3.0, a table library, session or running Cheat Engine that CE Decky cannot read is reported as unreadable, instead of looking empty or stopped.

## Install

On Decky Loader 3.3.0 an installed 0.9.29 or older cannot reach the network, so it will not offer this update. Turn on **Developer mode** in Decky, install `CE-Decky-v0.9.30.zip` from the file, then open the Quick Access Menu. Your tables, authorizations and profiles are kept.

On Decky Loader 3.2.8 an installed 0.9.28 or newer can install this from the panel itself; close any running game first.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
