## Features

- CE Decky updates itself: when a new release exists the panel shows an orange **Update to vX.Y.Z** button, and one confirmation installs it. Switch it off under **Advanced → Plugin updates**.
- The panel mascot can be hidden: **Advanced → Panel appearance**.

## Fixes

- Moving between this version and an older one no longer loses the registered Cheat Engine.
- A deletion the backend refuses no longer clears panel state, and **Delete everything** now also forgets the game you picked by hand.

## Install

Turn on **Developer mode** in Decky, install `CE-Decky-v0.9.28.zip` from the file, then open the Quick Access Menu. Your tables, authorizations and profiles are kept.

From this release on, the next update can be installed from the panel itself.

Requires Decky Loader 3.2.8+, Proton, ~230 MB free. Offline and single-player games only.
